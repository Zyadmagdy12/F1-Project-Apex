# PROJECT APEX v2.0 — VISUALIZATION EXECUTION PLAN (`VISUALIZATION_PLAN.md`)

## 1. Visual Identity & Technical Rendering Standards

All six panels adhere strictly to the Project Apex v2.0 engineering aesthetic and statistical fidelity rules:
- **Canvas & Resolution:** Exact 16:9 4K UHD (`3840 x 2160` pixels, rendered via `figsize=(19.2, 10.8)` at `dpi=200`).
- **Color Palette:**
  - Deep Carbon-Black Canvas: `#0A0D12`
  - Elevated Telemetry Card Surface: `#11161F` with `#1E2636` border strokes
  - Primary Accent (Neon Cyan): `#00E5FF`
  - Secondary Accent (Racing Orange): `#FF5500`
  - Positive / Verification Accent (Emerald): `#00E676`
  - Warning / Penalty / DNF Hazard Accent (Crimson/Amber): `#FF3366` / `#FFB300`
  - High-Contrast Typography: `#F8FAFC` (Primary), `#94A3B8` (Secondary), `#64748B` (Muted Grid/Labels)
- **Typography:** Clean tabular monospace (`Consolas` / `DejaVu Sans Mono`) for all numerical tables, matrices, intervals, and SHAP values; geometric sans-serif (`Segoe UI` / `DejaVu Sans`) for headers and annotations.
- **Anti-Hallucination & Data Fidelity:** Every number is dynamically read at runtime from `outputs/project_apex/*.csv` and `outputs/project_apex/*.json`. No values are hardcoded or altered for visual convenience.
